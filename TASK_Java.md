## Усложнение — работа с нереляционными базами данных

> **Выполнение на выбор: MongoDB или Redis**

### Вариант 1: MongoDB — Управление комментариями и пользовательскими сессиями

**Задача:** обеспечить хранение и эффективный поиск вложенных комментариев к любому типу контента, а также управлять пользовательскими сессиями.

- **Реализация:** использовать MongoDB как основное хранилище для сущности Комментарий (связанных с ID контента)
- **Требование:** демонстрация работы с гибкой схемой документов (вложенные ответы или метаданные)
- **Дополнительно:** использование MongoDB для хранения данных Spring Session или данных, связанных с управлением JWT-токенами

### Вариант 2: Redis — Система рекомендаций и аналитика в реальном времени ✅ (выбран)

**Задача:** реализация системы рекомендаций на основе популярности и сбор аналитики в реальном времени.

- **Реализация:** использовать Redis для быстрого доступа и обработки данных, требующих низкой задержки
- **Требование:** использование структуры Sorted Sets (ZSET) для ранжирования контента. Пример: «Топ-10 самых просматриваемых статей за час»
- **Дополнительно:** использование Redis в качестве кеша для часто запрашиваемых данных (с помощью `@Cacheable`) и атомарных счётчиков (`INCR`) для аналитики просмотров
