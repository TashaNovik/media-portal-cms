## Усложнение 2: Redis — Система рекомендаций и аналитика в реальном времени

### Задача
Реализация системы рекомендаций на основе популярности и сбор аналитики в реальном времени.

### Реализация
Использовать Redis для быстрого доступа и обработки данных, требующих низкой задержки.

### Требование
Использование структуры **Sorted Sets (ZSET)** для ранжирования контента.  
**Пример:** «Топ-10 самых просматриваемых статей за час».

### Дополнительно
- Использование Redis в качестве кеша для часто запрашиваемых данных (с помощью `@Cacheable`)
- Атомарных счётчиков (`INCR`) для аналитики просмотров

## Технические требования для Redis

1. **Sorted Sets (ZSET)** — для рейтинга контента по популярности
2. **Spring Cache с `@Cacheable`** — для кэширования часто запрашиваемых данных
3. **Атомарные операции `INCR`** — для счётчиков просмотров
4. **Настройка TTL** — для временных данных и кэша
5. **Spring Data Redis** — корректная конфигурация
